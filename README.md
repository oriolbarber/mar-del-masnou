# Mar del Masnou

App web instal·lable (PWA) per valorar si és bon dia per navegar al Masnou amb patí català, windsurf o Hobie Cat. Club Ocata Vent.

- Previsió: [Open-Meteo](https://open-meteo.com/) (atmosfèrica i marina)
- Vent en directe: [meteoelmasnou.cat](https://www.meteoelmasnou.cat/)

Obre-la a https://oriolbarber.github.io/mar-del-masnou/
